# Repository instructions

This repository contains an unpublished mathematical research manuscript.

- Work on a feature branch and use a pull request for substantive changes.
- Keep the main theorem status synchronized across the manuscript and README.
- Do not strengthen theorem claims solely on the basis of numerical or symbolic checks.
- Run the manuscript build for changes affecting LaTeX.
- Treat computational checks as reproducibility evidence, not formal certificates.
- Preserve the distinction between direct proof dependencies and research-provenance references.
- The manuscript is CC BY 4.0; code and build tooling are MIT licensed.
